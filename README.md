A pure-JavaScript, byte-exact drop-in for makefun-site 1.0.0 that builds each site in one pass: Latin-1 byte strings in and out,
Markdown rendered straight into JSON-escaped HTML, templates specialised and constant-folded per site, and the answers file
written as JSON text without a stringify pass.

## Run it

```sh
MAKEFUN_INPUT_DIR=practice/input MAKEFUN_OUTPUT_DIR=out node main.ts
```
